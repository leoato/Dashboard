# 오늘선생 · 오늘학생 — App Store 업로드 남은 단계

준비 작업은 끝났습니다. 아래는 **Apple 계정 자격증명이 필요해 직접 하셔야 하는** 단계입니다.

## 1. Xcode에서 서명 팀 지정 (앱마다 1회)

```bash
open "/Users/chadong-kyun/Documents/claude/Project/윤서과외/Dashboard/ios/teacher/ios/App/App.xcodeproj"
```

App 타깃 → **Signing & Capabilities** → `Automatically manage signing` 체크 → **Team**에 본인 개발자 계정 선택.
학생 앱도 동일하게:

```bash
open "/Users/chadong-kyun/Documents/claude/Project/윤서과외/Dashboard/ios/student/ios/App/App.xcodeproj"
```

## 2. App Store Connect에 앱 레코드 만들기

appstoreconnect.apple.com → 앱 → ＋ 새로운 앱

| | 오늘선생 | 오늘학생 |
|---|---|---|
| 이름 | 오늘선생 | 오늘학생 |
| 번들 ID | com.leoato.todayteacher | com.leoato.todaystudent |
| SKU | todayteacher | todaystudent |
| 기본 언어 | 한국어 |  한국어 |

> 이름이 이미 선점돼 있으면 `오늘선생 - 과외노트` 식으로 조정합니다.

## 3. 아카이브 → 업로드

Xcode에서 상단 기기 선택을 **Any iOS Device**로 바꾸고 **Product → Archive**.
Organizer가 열리면 → **Distribute App → App Store Connect → Upload**.

명령줄로 아카이브만 미리 만들려면:

```bash
cd "/Users/chadong-kyun/Documents/claude/Project/윤서과외/Dashboard" && ./ios/sync-web.sh && cd ios/teacher && npx cap sync ios && xcodebuild -project ios/App/App.xcodeproj -scheme App -configuration Release -destination 'generic/platform=iOS' -archivePath ~/Desktop/오늘선생.xcarchive archive
```

## 4. 스토어 정보 입력

- 스크린샷: `ios/screenshots/` 에 규격에 맞게 준비돼 있습니다 (선생 4장 1320×2868 / 학생 1장 2064×2752)
- 개인정보처리방침 URL: `https://leoato.github.io/Dashboard/docs/privacy.html`
- 카테고리: 교육 / 연령 등급: 4+
- **App Privacy 설문**과 **App Review Notes(영문)**: `ios/심사노트.md` §3·§1·§2 내용을 그대로 사용
- 수출 규정: 이미 `ITSAppUsesNonExemptEncryption=false`로 신고돼 있어 별도 질문이 뜨지 않습니다

## 5. TestFlight로 먼저 설치해보기

업로드가 처리되면 TestFlight 탭에 빌드가 뜹니다. 내부 테스터(본인)로 추가하면 **심사 없이** 바로 아이폰·아이패드에 설치됩니다.
여기서 실기기 검증(카메라 촬영, 사진 제출 왕복, 아이패드 가로 2단 풀이)을 마친 뒤 심사에 제출하세요.

## 6. 심사 제출 후

결과가 오면 `ios/심사노트.md` §6 표에 **승인이든 거절이든** 기록해 주세요. 거절 사유가 다음 앱의 가장 큰 자산입니다.
