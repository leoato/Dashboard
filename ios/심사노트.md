## 1. App Review Information → Notes 에 붙여 넣을 영문 (오늘선생)

```
ABOUT THIS APP
"오늘선생" (Today Teacher) is a private tool for a one-on-one after-school
math tutor to manage a single student's lessons: recording what was covered,
assigning worksheets, reviewing the student's handwritten solutions, and
drafting a progress message for the parent.

It is the teacher-side companion to "오늘학생" (Today Student), which the
student uses on an iPad. The two apps exchange worksheets and submissions.

NO ACCOUNT IS REQUIRED
The app opens directly in DEMO MODE with no sign-in. Every screen and feature
is reachable without any credentials. Cloud sync and AI question generation
are optional and only activate if the user enters their own Supabase project
URL / API key under the "설정" (Settings) tab — we do not ship any keys.

HOW TO REVIEW
1. Launch the app. It opens on the "오늘" (Today) tab in demo mode.
2. Tap "오늘 수업 종료" (End today's lesson) to see the core flow:
   progress → homework → one comment → an auto-composed parent message.
3. "수업 기록" shows saved lessons and messages.
4. "문제지·자료" is where a worksheet is created and sent to the student app,
   and where submitted answers and photos of handwritten work are reviewed.
5. "학생" holds the student profile, scores and weak-point notes.

CAMERA USAGE
The camera is used only to photograph paper worksheets and handwritten
solutions so they can be attached to a lesson record. Nothing is uploaded
unless the user has configured their own cloud project.

WORKS OFFLINE
All assets are bundled locally; the app runs without a network connection.

The interface is Korean, as the app is for Korean tutoring.
```

## 2. 오늘학생 용 영문 (연결 코드가 있으므로 반드시 포함)

```
ABOUT THIS APP
"오늘학생" (Today Student) is the student-side companion to "오늘선생".
A tutoring student receives worksheets from the teacher, writes the solution
on paper, types only the answers into the iPad, gets instant grading, and
photographs the paper so the teacher can review the working steps.

>>> HOW TO GET IN (IMPORTANT) <<<
The first screen asks for a connection code from the teacher.
Type   DEMO   (or 데모) into the field and tap "연결".
This opens the app in demo mode with sample worksheets. No account,
no server, and no code from us is required.

HOW TO REVIEW (after entering DEMO)
1. "새로운 문제" — open a worksheet, type answers, tap grading.
2. "오답모음" — review previously wrong questions.
3. "질문하기" — send a question to the teacher (inert in demo mode).
4. The camera button attaches a photo of the paper solution.

CAMERA USAGE
Only to photograph the student's own handwritten solution on paper so the
teacher can see the working steps. No upload occurs in demo mode.

BEST VIEWED
iPad, landscape orientation (the solving screen is a two-pane layout).

The interface is Korean, as the app is for Korean tutoring.
```

## 3. App Privacy(개인정보 보호) 설문 답안 — 실제 동작과 일치해야 한다

수집하는 데이터로 신고할 항목 (모두 **앱 기능 제공 목적**, **사용자에게 연결됨**, **추적 아님**):

| 카테고리 | 항목 | 비고 |
|---|---|---|
| Contact Info | Name | 학생 이름 (선생님이 입력) |
| Contact Info | Phone Number | 학부모 연락처 — **선택 입력**. 입력 안 하면 수집 없음 |
| User Content | Photos or Videos | 손풀이 사진 |
| User Content | Other User Content | 진도·숙제·성적·오답·질문 |

**신고하지 않는 것**(실제로 수집하지 않음): 위치, 광고 식별자, 사용 데이터/분석, 구매 이력, 검색 기록, 연락처 목록.
"Data Used to Track You" → **없음**. "Third-Party Advertising" → **없음**.

## 4. 스토어 메타데이터 초안

- 카테고리: 교육 (Education)
- 연령 등급: 4+
- 개인정보처리방침 URL: `https://leoato.github.io/Dashboard/docs/privacy.html`
- 수출 규정: 표준 암호화(HTTPS)만 사용 → `ITSAppUsesNonExemptEncryption = false` (Info.plist에 이미 반영)
- 지원 URL: `https://leoato.github.io/Dashboard/docs/설명서.html`

**부제·설명 초안 (오늘선생)**
> 부제: 과외 수업 기록과 학부모 안내를 한 번에
> 설명: 수업이 끝나면 버튼 하나로 진도·숙제를 기록하고, 학부모에게 보낼 안내 문자까지 자동으로 완성됩니다. 문제지를 만들어 학생 태블릿으로 보내고, 학생이 종이에 푼 풀이를 사진으로 확인할 수 있습니다.

**부제·설명 초안 (오늘학생)**
> 부제: 선생님이 보낸 문제지를 풀고 바로 채점
> 설명: 선생님이 보낸 문제지를 아이패드로 받아 풀고, 답을 입력하면 즉시 채점됩니다. 종이에 쓴 풀이는 사진으로 찍어 선생님께 전달되고, 틀린 문제는 오답 모음에서 다시 볼 수 있습니다.
