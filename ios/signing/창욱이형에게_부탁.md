# 창욱이형, 애플 개발자 사이트에서 10분만 부탁드립니다

브라우저만 있으면 됩니다. Xcode 설치 필요 없습니다.
아래 3가지를 만들어서 파일 4개를 저(동균)에게 보내주시면, 이후 빌드·업로드·심사 제출은 제가 다 합니다.
**한 번만 해두면 다음 배포부터는 형 손이 안 갑니다.**

준비물: 제가 같이 보낸 파일 `파로한스_배포인증서요청.certSigningRequest`

---

## 1) App ID 2개 등록

https://developer.apple.com/account → **Certificates, Identifiers & Profiles** → 왼쪽 **Identifiers**

오른쪽 **＋** 버튼 → **App IDs** 선택 → Continue → **App** 선택 → Continue

| 칸 | 첫 번째 | 두 번째 |
|---|---|---|
| Description | Today Teacher | Today Student |
| Bundle ID | **Explicit** 선택 후 `com.leoato.todayteacher` | **Explicit** 선택 후 `com.leoato.todaystudent` |
| Capabilities | 아무것도 건드리지 않음 | 아무것도 건드리지 않음 |

Continue → Register. 이 과정을 두 번 반복합니다.

## 2) 배포 인증서 발급

왼쪽 **Certificates** → 오른쪽 **＋**

1. **Apple Distribution** 선택 → Continue
2. **Choose File** 눌러 제가 보낸 `파로한스_배포인증서요청.certSigningRequest` 업로드 → Continue
3. **Download** 눌러 `.cer` 파일 저장

> 이미 배포 인증서가 있다면 새로 만들지 마시고 기존 것을 Download 해주셔도 됩니다.

## 3) 프로비저닝 프로파일 2개 생성

왼쪽 **Profiles** → 오른쪽 **＋**

1. **Distribution** 항목의 **App Store Connect** 선택 → Continue
2. App ID 드롭다운에서 `com.leoato.todayteacher` 선택 → Continue
3. 방금 만든 인증서 선택 → Continue
4. Profile Name: `Today Teacher AppStore` → Generate → **Download**
5. 같은 방법으로 `com.leoato.todaystudent`도 → 이름은 `Today Student AppStore`

---

## 보내주실 파일 4개

1. `.cer` (배포 인증서)
2. `Today_Teacher_AppStore.mobileprovision`
3. `Today_Student_AppStore.mobileprovision`

(3개네요. 카톡으로 보내주시면 됩니다.)

**주의:** 계정 비밀번호는 알려주지 않으셔도 됩니다. 위 파일만 있으면 제가 서명해서 올릴 수 있습니다.
