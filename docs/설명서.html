1두 개의 앱 설치하기

회원가입 없습니다. 주소를 열고 홈 화면에 추가하면 앱이 됩니다.

  1. 선생님 기기에서 오늘선생을 엽니다leoato.github.io/Dashboard — 노트북이면 그냥 즐겨찾기로 충분합니다.
  2. 학생 태블릿에서 오늘학생을 엽니다같은 주소 뒤에 /student.html — 사파리에서 공유 → "홈 화면에 추가"를 누르면 아이콘이 생깁니다.
  3. 업데이트는 신경 쓰지 않아도 됩니다앱이 새 버전을 스스로 확인해 다음에 열 때 갱신합니다.

2학생 등록과 연결 — 제일 중요

학생을 등록하지 않으면 앱이 이름 대신 "학생"이라고만 부르고, 태블릿을 연결하지 않으면 문제지가 오가지 않습니다.

  1. 오늘선생 → 학생 탭에서 학생을 추가합니다이름과 과목만 넣으면 됩니다. 이후 화면·학습지·문자에 이 이름이 자동으로 들어갑니다.
  2. 설정 탭에서 Supabase 주소와 키를 넣습니다처음 한 번만. 한 줄짜리 설치 안내는 프로젝트의 supabase-setup-guide.md에 있습니다.
  3. [태블릿 연결 코드 복사]를 누릅니다코드에는 접속 정보와 학생 이름이 담깁니다. 카톡으로 태블릿에 보내세요.
  4. 오늘학생 첫 화면에 코드를 붙여넣고 [연결]오른쪽 위가 "연결됨"으로 바뀌면 끝입니다.

등록이 끝나면 오늘 탭에 학생 카드가 뜹니다

Supabase를 안 넣으면 "데모 모드"입니다

그 기기 안에서만 동작하고 태블릿과 오가지 않습니다. 기능을 먼저 구경할 때는 편하지만, 실제 수업에는 연결을 꼭 마치세요.

05

3수업 끝나고 — 진도와 문자

수업이 끝나면 이 버튼 하나만 누르면 됩니다. 3단계, 1분입니다.

  1. 오늘 탭 → [오늘 수업 종료]1번 항목에 "지난 숙제 풀이"가 미리 들어가 있습니다. 오늘 나간 내용을 이어 적으세요.
  2. 숙제를 적고 넘깁니다없으면 비워두고 넘어가도 됩니다.
  3. 그날의 한마디만 씁니다오른쪽 미리보기에 학부모 문자가 실시간으로 완성됩니다.
  4. [저장하고 문자 완성] → [문자 복사]진도와 문자가 동시에 저장되고, 복사한 문자를 카톡에 붙여넣으면 끝입니다.

한마디를 적으면 문자가 완성된 상태

인사말과 마무리 문구는 바꿀 수 있습니다

설정 탭 → 안내 문자 템플릿에서 고치면, 다음 문자부터 그 문장으로 나갑니다. 매번 다시 쓸 필요가 없습니다.

06

4문제지 보내고 받기

만드는 방법은 두 가지입니다.

방법 A — 앱에서 만들기 (쉬움)

  1. 문제지·자료 탭 → [＋ 새 문제지] → [Gemini로 문제 만들기]단원을 대·중·소로 고르고 문항 수·난이도만 정하면 됩니다.
  2. 검수하고 전송정답을 확인하고 이상한 문항은 ✕로 뺀 뒤 보냅니다. 학생용에는 정답이 들어가지 않습니다.

방법 B — PDF 올리기

  1. 제목·정답을 적고 PDF를 첨부해 전송정답을 쉼표로 적어두면 학생이 제출할 때 자동 채점됩니다.

단원을 고르면 그 범위 안에서만 출제됩니다

학생이 제출하면 오늘 탭에 알림이 뜹니다

알림을 눌러 제출물을 열면 점수·문항별 ○✕·손풀이 사진을 볼 수 있고, 그때부터 학생에게 해설이 열립니다.

07

5오답과 질문

학생 쪽에서 일어나는 일입니다.

  1. 학생은 종이에 풀고 답만 입력합니다√ 같은 기호는 버튼으로 넣거나 "2루트5"라고 적어도 됩니다.
  2. 풀이 종이를 찍어 제출사진이 있어야 제출됩니다. 선생님이 풀이 과정을 봐야 하니까요.
  3. 틀린 문제는 오답모음에 쌓입니다한 번에 모아보기 / 단원별로 모아보기 두 가지로 볼 수 있습니다.
  4. 막히면 질문하기문제를 고르고 교재 사진을 붙여 보내면, 선생님 질문함에 문제 원문·정답과 함께 도착합니다.

질문에 답하면 학생 화면에 바로 뜹니다

6자주 묻는 것

문제지를 보냈는데 태블릿에 안 떠요.

학생 앱 오른쪽 위가 "데모 모드"면 연결이 안 된 상태입니다. 그 글자를 눌러 연결 코드를 다시 붙여넣으세요. "연결됨"이면 새로고침 한 번이면 뜹니다.

정답을 맞게 썼는데 틀렸다고 나와요.

답의 표기가 다른 경우입니다. 루트·마이너스 표기는 앱이 알아서 맞춰주지만, 분수를 소수로 쓰는 등 형태가 다르면 다르게 봅니다. 문제지를 만들 때 정답 표기를 단순하게(3, -2, 5/2, √5) 정하는 게 좋습니다.

문제 생성이 503 오류가 나요.

고장이 아닙니다. 구글 무료 서버가 붐비는 시간입니다. 앱이 자동으로 재시도하고 다른 모델로도 넘어가지만, 그래도 실패하면 1~2분 뒤 버튼만 다시 누르면 됩니다. 입력한 내용은 그대로 있습니다.

노트북에서 적은 진도가 아이패드에 안 보여요.

앱을 열면 더 최신 데이터를 자동으로 받아옵니다. 오른쪽 위 동기화 표시가 "미저장"이면 잠시 기다리거나 동기화 창에서 [클라우드에 저장]을 누르세요. 오래된 데이터로 덮어쓰지 않도록 앱이 먼저 확인합니다.
